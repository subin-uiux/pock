# Legacy (정적 마크업 참고)

- 앱 진입점: 루트 `index.html` → `src/`
- 디자인 시스템: React `/guide` (`src/pages/GuidePage.tsx`)
- 옛 정적 가이드 원본: `legacy/pages/guide.html`
- 이 폴더는 실행하지 않습니다. 참고용으로만 둡니다.
- `guide.html` 안의 `assets/css`·`assets/js` 경로는 전환 전 링크입니다. 현재 앱 CSS는 `src/styles/`, 정적 파일은 `public/assets/`만 사용합니다.
