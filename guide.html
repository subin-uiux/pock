POCK · Button system

BUTTON

역할 + 상태 + 타입 = 하나의 버튼

총 3가지 버튼 유형 | Push_btn · Popup_btn · Action_btn

상태는 Default / Pressed를 기준으로 하며, 버튼의 용도에 따라 Guide 및 Icon 타입을 함께 사용합니다. Push는 주요 액션, Popup은 팝업 내 액션, Action은 Icon / Text 타입의 기능 실행 버튼으로 사용합니다.
